## Project Name: 
Twilio Area Code Map

## Purpose: 
Allow Twilio customers to get a visual of Twilio's inventory and insight into available overlays that Twilio offers for regions.

Live Demo: https://twilio-prefix-map-na-8377-dev.twil.io/index.html

## Features  
- **Dynamic Shapes**: Interactive shapes display quantity of each prefix that is available for the region when clicked.
- **Search**: Search by area code, city, or address.
- **Display numbers based on rate center**: Can search for all XXX-XXXX combinations to get more local search results

## Technologies Used
- **Frontend**: Bootstrap, React, Leaflet 
- **Backend**: Node.js, Nominatim API, Local Calling Guide, Twilio API
- **Deployment**: Twilio Serverless Functions
